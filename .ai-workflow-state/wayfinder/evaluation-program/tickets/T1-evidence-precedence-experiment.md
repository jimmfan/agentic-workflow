# T1: Run the preregistered evidence-precedence experiment

- Status: ready
- Blocked by: none
- Related: D1, D3, D4, U3

## Outcome

The exact next experiment is a focused, sequential, context-isolated paired campaign that reproduces the clean Resume rerun's clearest failure mode before the larger Wayfinder study:

1. Phase 1 gives each fresh baseline and default-Agentic-Workflow agent an exact approved fact and an unresolved consequential decision. The agent may preserve the fact in live source or repository notes but must not guess the unresolved decision.
2. The harness removes the transient source, then commits a newer approved decision that resolves the withheld question and is intentionally silent about—without contradicting—the Phase 1 fact.
3. A completely fresh Phase 2 agent must preserve the still-valid fact, apply the new decision, complete the implementation, and verify it.
4. Run matched repeated baseline/workflow trials sequentially with frozen prompts, mutations, grader, model/configuration, and per-run context audits.

This ticket authorizes an evaluation campaign when separately taken up; it does not authorize changing product behavior.

## Acceptance

- The protocol, sample count, evaluator, analysis rules, and evidence-quality labels are preregistered before live execution.
- Safety, fact preservation, speculative work, removal of valid evidence, completion, correctness, and verification are reported separately.
- Old conversations cannot be reused for Phase 2; every evaluated phase has an independently created fresh conversation.
- Cost/usage is captured only if reliably exposed; otherwise it remains unavailable.
- Results are reported as focused evidence about evidence precedence, without claiming Wayfinder efficacy or general product value.
