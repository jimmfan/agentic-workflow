## Controls and limitations

The TOML scenarios use the existing evaluator for narrow structural and textual signals.
The exact-order assertion applies only to the explicit new default-map request; alternate-layout preservation is a separate bounded resumption scenario.
Evaluator tests accept source-linked and brief source-linked orientation examples and reject controlled losses of provider/decision-maker, invented approval, stale mirrored maintenance, false blocker absence, and default-format rewrites of the alternate map.
These controls test the evaluator, not live semantic compliance.
Human inspection must still reject invented authority from access or implementation, unjustified readiness or blocking, lost relationships, inadequate references and unknowns silently converted into absence; arbitrary prose cannot be reliably graded with keywords.

Report PASS, FAIL or INCONCLUSIVE separately from infrastructure-blocked execution.
One successful synthetic sequence establishes neither general reliability nor comparative advantage.
