# Bounded decision discovery

Discovery owns decision-resolution methodology, not durable continuity. Do not
load it for every choice: continue directly when the decision can be resolved
safely without its method.

## Establish the boundary

1. Read the project profile only for relevant facts and commands.
2. Establish the mutation boundary. A read-only request stays ephemeral; a
   provisional choice is not authorization to write.
3. In standalone use, resolve the bounded decision and return the result without
   creating DEC or another framework record. If consequential coordination must
   survive a session or several state distinctions cross the Wayfinder
   threshold, select Wayfinder; its map becomes the only framework re-entry
   point.
4. When Wayfinder selected Discovery for a frontier, use only the relevant map,
   U#/E#/F#/D# detail, and canonical artifacts. Wayfinder owns continuity and
   later reconciliation; Discovery creates no competing notebook or record.

## Resolve the decision

1. State the precise question and why it blocks or materially changes the work.
2. Separate verified facts, constraints, assumptions, preferences, unknowns,
   and out-of-scope matters. Inspect repository evidence before asking for facts
   the workspace can answer.
3. Use primary sources for consequential or time-sensitive external facts. Load
   upstream Research only when its cited durable artifact and isolated work add
   value; otherwise keep the lookup proportional.
4. Compare only viable alternatives by benefits, costs, risks, reversibility,
   and evidence that would change the choice.
5. Mark a consequential decision accepted only when the user accepts it or a
   named project policy delegates authority. Autonomous progress may make only a
   reversible provisional choice with an explicit review trigger.

If the user explicitly wants sustained learning before deciding, Teach may be a
separate capability when its dedicated workspace materially helps. Teaching
does not decide the question or create Discovery continuity.

## Return the result

Report the decision status, rationale, consequences, rejected alternatives,
remaining uncertainty, authority, and next handoff. In Wayfinder use, return
those consequential results for reconciliation into the current map and only
independently useful U/E/F/D knowledge. A committed local D# remains
effort-scoped; a lasting architecture decision belongs in the project's
canonical ADR convention. Preserve external issue IDs and provider-native
identifiers unchanged.
