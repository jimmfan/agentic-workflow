# Wayfinder follow-up proposals

- Status: deferred
- Last reviewed: 2026-08-20

These are high-value questions to evaluate after the selective-promotion change.
They are not current policy. Accepted behavior remains governed by the ADRs,
runtime projection, and Wayfinder state contract.

## Define decision-ready mechanics only if judgment proves insufficient

Evaluate whether agents need a sharper shared vocabulary for a consequential
decision boundary, sufficient evidence, explicit acceptance of residual
uncertainty, and the difference between local blocking and effort completion.
Avoid adding scores, schemas, or lifecycle states until repeated failures show
that the current judgment-based rule is not reliable.

## Repeat the behavioral comparison with controls

Compare the original reference, an unmodified replacement control, and the
patched replacement in clean repository copies. Use a cheaper model such as
Claude Haiku for screening, then confirm only meaningful differences with
Sonnet. Grade map quality, selective U# promotion, unsupported state growth,
authority safety, and evidence-backed dependency clarity. Include a negative
control whose backlog does not establish a critical path.

## Test fresh-agent continuation when time permits

Give the produced state to a fresh agent and test whether it can identify the
destination, consequential unknowns, authority-owned blockers, dependency-safe
ready frontier, and next responsible action without loading every child. This
would measure the continuation value directly rather than treating file
creation as the outcome.

## Revisit triggers

Reconsider these proposals if live evaluations show repeated scope drift,
agents getting stuck on territory, inconsistent effort reconstruction,
consequential questions buried only in the map, or needless U# proliferation.
